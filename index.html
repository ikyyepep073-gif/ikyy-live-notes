Konfigurasi Firebase

Buat Firebase project → Realtime Database → Web App. Tempel objek config dari Firebase di bawah ini, lalu klik Simpan config. Jangan tempel password atau private key.

  1. Buka console.firebase.google.com dan buat project.
  2. Build → Realtime Database → Create Database.
  3. Project settings → General → Add app → Web () lalu salin Firebase config.
  4. Realtime Database → Rules, gunakan rules contoh yang ada di file database.rules.json dari paket ini hanya untuk uji coba. Rules publik mengizinkan orang lain membaca/menulis data; gunakan kode ruang yang tidak mudah ditebak dan jangan simpan informasi sensitif.
  5. Unggah index.html ke hosting HTTPS seperti GitHub Pages. URL yang sama dipakai untuk editor dan overlay.
